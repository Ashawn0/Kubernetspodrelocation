# Non-goals

These are excluded design decisions, not omissions.

- Custom scheduler, scheduler extender, or harness-written Pod Binding for placement
- `spec.nodeName` as the forced-placement mechanism (allowed only as a Stage 0 negative control)
- Reinforcement learning / sequential decision loops
- Neural predictors
- Building the LightGBM campaign, oracle, or GapCaptured pipeline during Stage 0
- Treating kind construct-invalid PSI or shared-NIC registry delay as paper-ready target-node features
